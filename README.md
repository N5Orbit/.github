# N5Orbit organization defaults

This public repository distributes GitHub community-health defaults to eligible repositories in the [N5Orbit organization](https://github.com/N5Orbit).

## Issue intake

The organization-wide default Issue Form is maintained at [`.github/ISSUE_TEMPLATE/n5-work-item.yml`](.github/ISSUE_TEMPLATE/n5-work-item.yml), implementing the reviewed [N5 Issue Contract v1](https://github.com/N5Orbit/shared/blob/main/ai/standards/issue-contract-v1.md).

GitHub only inherits these defaults in repositories **without** their own valid issue templates or template configuration; local templates take precedence. A new Issue is a specification and tracking artifact, **not authorization** for an agent to execute, merge, deploy, spend money, or alter permissions. Work follows owner-approved routing, independently reviewed pull requests, and documented decision gates.

This repository is public by GitHub requirement. Do not publish private issue details, credentials, private infrastructure information, or internal conversation content here.

Governance migration tracking: [N5Orbit/.github#1](https://github.com/N5Orbit/.github/issues/1).
